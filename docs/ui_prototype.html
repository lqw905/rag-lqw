请问在浙江省高考志愿填报中，“高校专项计划”的报名资格和投档录取规则是什么？如果未被录取会影响后续普通批次吗？

根据《2025年浙江省普通高校招生工作实施意见》及相关高校招生章程，关于高校专项计划的核心政策解答如下：

1. 报考资格要求[1]：

  • 符合当年统一高考报名条件；
  • 本人及父亲或母亲或法定监护人户籍在实施区域的农村，本人具有当地连续3年以上户籍；
  • 本人具有户籍所在县（市、区）高中连续3年学籍并实际就读。

2. 投档与录取规则[2]：

高校专项计划安排在特殊类型招生批次进行投档录取。考生高考总分原则上需达到浙江省特殊类型招生控制线（一段线），高校依据经公示的入选资格考生名单及填报志愿，按学校招生简章规定的规则择优录取。

3. 对后续普通批次的影响[3]：

完全不影响！高校专项计划属于单独批次填报与录取。若考生未被专项计划录取，其档案将正常参与后续的普通类平行志愿（一段/二段）投档录取，相当于为农村学子多提供了一次进入顶尖高校的机会。
