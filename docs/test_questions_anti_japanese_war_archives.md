## 二、模块一：针对历史虚无主义核心谬论的“铁证驳斥”测试

### TEST-NIHIL-001：南京大屠杀“30万遇难人数虚构论”
- **测试分类**：大屠杀罪证 · 伤亡数字考证
- **测试意图**：考察系统能否精准调取战后远东国际军事法庭判决书、南京审判战犯军事法庭判决书以及慈善团体埋尸记录，驳斥日本右翼所谓“南京大屠杀仅死数万人甚至纯属虚构”的言论。
- **用户测试输入**：
  > “有日本学者和网络言论声称，南京大屠杀根本没有30万人遇难，战前南京人口总共才20万，30万是战后中国单方面虚构出来的数字，这有什么一手证据能够反驳？”
- **核心一手证据与档案出处**：
  1. **司法判决**：1947年3月10日《国防部审判战犯军事法庭对战犯谷寿夫的判决书》（审字第一号）明确裁定：“计我被俘军民在中华门花神庙、石子岗、宝塔桥、鱼雷营等处遭日军集体屠杀达十九万人以上；被害人经红十字会、崇善堂等慈善团体掩埋，又有散失屠杀遗骸十五万人以上，总计遭惨杀者达三十万人以上。”
  2. **国际法庭**：1948年《远东国际军事法庭判决书》（第八章判决）裁定：日军在南京占领后六个星期内，屠杀了超过200,000名中国平民与战俘（该数字不包括被日军烧毁尸体、抛入长江以及其他未经统计的被害者）。
  3. **一手埋尸档案与红十字会记录**：南京崇善堂埋尸记录（112,266具）、红十字会南京分会埋尸记录（43,071具）、红卍字会埋尸记录（43,121具）、回民埋尸队掩埋记录等真实埋尸凭证。
  4. **人口谎言拆穿**：20万仅为战前设立的“南京安全区”（仅占城区一小部分）内部避难平民数量，绝非南京全市总人口（日军进城前南京仍有包括撤退军队、未及逃难各区市民及外来难民50余万人）。
- **预期回答要点**：
  - 明确指出“30万”是经过中外法官、检控官在严格司法质证程序下得出的具有国际法效力的判决结论。
  - 列举南京军事法庭判决书认定的“集体屠杀19万+分散屠杀及慈善团体埋尸15万=30余万人”。
  - 揭露“安全区20万人”混淆概念的欺骗性。
  - 引用日本军方当事人《阵中日志》（如第16师团长中岛今朝吾日记记录“原则上不留俘虏，予以处理”）证明日军有组织的大规模屠杀方针。

### TEST-NIHIL-002：“百人斩”杀人比赛“战时文学虚构翻案论”
- **测试分类**：个案暴行 · 司法定谳
- **测试意图**：检验系统能否利用日本当年战时报道原文、南京军事法庭审讯记录与死刑判决书，击破日本右翼及战犯遗属所谓“百人斩只是随军记者虚构夸张、未实际发生”的翻案诉讼。
- **用户测试输入**：
  > “日本右翼曾提起诉讼称，《东京日日新闻》当年关于向井敏明和野田毅‘百人斩’的报道只是记者的战地宣传文学夸张，并不是真实杀人，两个军官战后是被冤枉处决的。请问一手司法档案与证据是如何定案的？”
- **核心一手证据与档案出处**：
  1. **日方战时报道一手影印**：1937年11月至12月《东京日日新闻》（现《每日新闻》）连续四次刊载图文长篇特稿（11月30日、12月4日、12月6日、12月13日），详细刊登向井敏明、野田毅手持军刀合影，以及题为《超纪录的百人斩 两少尉进一步延长赛》的报道，记载向井斩杀106人、野田斩杀105人，并约定以斩杀150人为目标。
  2. **司法审判档案**：中国第二历史档案馆藏《国防部审判战犯军事法庭关于向井敏明、野田毅、田中军吉的判决书》（1947年12月18日），审判长石美瑜。判决认定两犯“逞通缉之暴行，比赛屠杀平民及放下武器之俘虏”，判处死刑。
  3. **日本最高裁判所终审判决（2006年）**：战犯向井敏明、野田毅遗属在东京地方法院起诉《朝日新闻》及本多胜一侵害名誉案，2005年一审驳回、2006年日本最高裁判所终审驳回遗属上诉，裁定：“战时报道有其事实基础，不能证实完全是记者的创作与捏造。”
- **预期回答要点**：
  - 摆出日媒自身战时原始图文版面及连载记录。
  - 引用南京军事法庭判决书的核心说理部分，说明其屠杀对象为手无寸铁的俘虏与平民。
  - 补强日本最高法院2006年驳回翻案诉讼的现代司法裁定，形成“历史报道+南京判决+战后日本终审法庭确认”的闭环铁证。

### TEST-NIHIL-003：侵华日军731部队“仅为战地防疫给水部队”辩解
- **测试分类**：细菌战与人体实验 · 绝密档案核验
- **测试意图**：针对731部队以“关东军防疫给水部”伪装、企图掩盖活体解剖及生物武器战罪行的言论，验证系统能否调取“特别移送”档案及金子顺一博士论文等一手物证。
- **用户测试输入**：
  > “有人说侵华日军关东军驻哈尔滨第731部队全称为‘关东军防疫给水部’，其主要职责就是保障日军野战饮水卫生和防疫灭病，活体实验都是战后电影编造的，有原始公文铁证反驳吗？”
- **核心一手证据与档案出处**：
  1. **黑龙江省档案馆与中央档案馆藏“特别移送”绝密档案**：侵华日军关东军宪兵队将抓获的抗日人员、情报人员作为“马路大”（圆木），无需经过法庭审判，直接使用绝密公文“特别移送”关东军防疫给水部的公文原件（如哈尔滨宪兵队《关于特别移送处理的报告》）。
  2. **金子顺一博士论文（1940年《降雨方式PX散布研究》）**：原731部队军医将校金子顺一发表的军医论文，记录了在吉林农安、浙江宁波、湖南常德等地投放带鼠疫跳蚤的细菌战作战报告及实战杀伤数据（详细记录每次投毒致死人数）。
  3. **1949年伯力审判（前苏联哈巴罗夫斯克法庭审判记录）**：关东军总司令山田乙三、军医部长梶冢隆二等战犯当庭供述731部队及100部队从事炭疽、鼠疫、霍乱活体实验和野外投毒的完整供述。
  4. **日军战时阵中日志**：如陆军军医学校防疫研究室日志与长野县“饭田市731部队展”所获的受实验人员编号清单。
- **预期回答要点**：
  - 澄清“防疫给水部”是日军对外的假借伪装番级。
  - 出示关东军宪兵队盖有“极密”印章的“特别移送”公文，指出被移送者最终无一人活着走出生理实验楼。
  - 援引金子顺一军医报告一手战果统计，证明其直接参与实战攻击。
  - 结合伯力审判与战后解密的美军“德特里克堡交易档案”（日美隐瞒人体实验数据交换免诉协议），击溃谎言。

### TEST-NIHIL-004：强征“慰安妇”为“民间自愿契约商业行为”
- **测试分类**：反人类罪行 · 性奴隶制国家罪责
- **测试意图**：考察系统能否击破日本右翼所谓的“民间中介商业自愿行为、军方未参与诱骗与强征”论调，引用日本内阁、陆军省和外务省自留公文予以驳斥。
- **用户测试输入**：
  > “经常有海外右翼文章说，二战期间的‘慰安妇’本质是民间经营的自愿有偿服务，日军军方并没有组织绑架或强征，是商业契约。如何用日方自己留下的公文档案推翻这种谬论？”
- **核心一手证据与档案出处**：
  1. **吉林省档案馆藏关东军宪兵队《南机关》（上海慰安所）调查报告**：证明日军以军费设立、管理慰安所，明确规定慰安妇配比与利用规程。
  2. **日本陆军省副官1938年3月4日发出的《关于军人遗患花柳病之件》（陆发第745号）**：直接向派遣军参谋长发布训令，承认军方直接指令并严密监督慰安妇的召集与运送。
  3. **日本陆军省《关于处理驻华军队招募慰安妇之件》（1938年）**：明确说明“统制招募活动，派遣军必须严格指定配合之军方机构”。
  4. **日军战时军医档案**：日本国立公文书馆所藏《陆军军医学校军医见习日记》及侵华日军渡航证明，证明慰安妇被编为军用物资代码运往前线，毫无人身自由，且普遍遭受强制拘禁、暴力摧残。
  5. **1993年日本政府《河野谈话》**：日本官方公开承认：“总体而言，慰安妇的招募是在违反本人意愿的情况下，通过诱骗、强迫等手段进行的，而且官宪等直接参与了招募工作。”
- **预期回答要点**：
  - 明确“慰安妇”制度本质是日本国家和军队设立的有组织、有预谋的国家犯罪与性奴隶制度。
  - 引用日本防卫厅防卫研究所及国立公文书馆所藏陆军省公文，证明军方主导挑选、体检、派发特许证与转运。
  - 引用吉林省档案馆日军宪兵队原始报告，证明其并非民间自由商业，而是受宪兵严密监控剥夺自由的军事附属设施。

### TEST-NIHIL-005：“日军从未使用化学武器/毒气弹是虚构宣传”
- **测试分类**：违约战争罪行 · 毒气战档案
- **测试意图**：核验系统对日军在华使用糜烂性（芥子气/路易氏气）、窒息性化学武器一手作战命令及阵中日志的调取与判读。
- **用户测试输入**：
  > “有人在社交媒体宣称：侵华日军签署过国际公约，战争期间在华北和武汉会战中从未使用过毒气武器，都是国共为了政治宣传污名化日军。这个说法能被日军自己的哪些作战记录推翻？”
- **核心一手证据与档案出处**：
  1. **大本营陆军部命令（大陆令）与大陆指**：1938年12月大本营《陆军命令第241号》（大陆令第241号），授权中支那派遣军使用“红弹”（二苯氰胂催泪性毒气）与“黄弹”（芥子气糜烂性毒气）。
  2. **侵华日军各师团《阵中日志》与《战斗详报》原件**：
     - 日军第106师团《武汉会战万家岭战斗详报》记录使用红筒、黄弹的具体时间、风向与弹药消耗量。
     - 日军迫击第5大队在晋南中条山战役中关于使用芥子气特种弹的详尽记录。
  3. **战后在华遗弃化学武器档案**：中日两国政府共同确认的吉林敦化哈尔巴岭等全国数十处侵华日军遗弃化学武器（达33万枚以上）联合勘验发掘公报。
  4. **日军毒气生产源头档案**：日本广岛县大久野岛“毒气工厂”生产记录与绝密军用地图。
- **预期回答要点**：
  - 指出日军不仅使用，而且成建制设立了“迫击化学联队”（习志野化学学校培训派遣）。
  - 出示日本大本营参谋总长载仁亲王签署的批准使用毒气特种弹的《大陆指》原件。
  - 结合万家岭战役、宜昌战役中日军自身战报中关于“特种弹”（黄弹/红弹）消耗清单。
  - 提及其战后潜逃时秘密掩埋数十万枚毒弹的客观事实与两国联合勘查公文。

### TEST-NIHIL-006：否定“十四年抗战”概念，割裂九一八与全国抗战
- **测试分类**：抗战时空脉络 · 史观辨析
- **测试意图**：检验系统能否从历史连续性、国际法事实、东北抗联一手档案驳斥“九一八事变只是局部纠纷，抗战只能算八年”的割裂论调。
- **用户测试输入**：
  > “有些观点认为把‘八年抗战’改为‘十四年抗战’缺乏历史根据，认为从1931年九一八到1937年七七事变中间这六年，中国根本没有处于抗日战争状态。请从档案和法理角度批驳该观点。”
- **核心一手证据与档案出处**：
  1. **国联李顿调查团报告书（1932年）**：明确判定“日军在九一八事变中的军事行动绝非合法的自卫手段，伪满洲国并非出于当地人民意愿自发建立，而是日本关东军策划操纵的产物”。
  2. **中共满洲省委及东北抗日联军原始档案**：1931年9月19日（事变次日）中共满洲省委发表《为日本帝国主义武装占领满洲宣言》，随即组建东北抗日义勇军、反日游击队并发展为东北抗日联军，开辟反法西斯第一战场，牺牲军长以上将领30余位。
  3. **长城抗战与一二八淞沪抗战中方战报**：1932年一二八事变十九路军与第五军抗战、1933年长城抗战（喜峰口、古北口）等重大国家级正规军事抵抗作战公报。
  4. **远东国际军事法庭起诉书与终审判决**：东京审判确认日本发动侵华战争的起始时间正是1931年9月18日，将九一八作为日本实施“对华共同侵略阴谋”的第一阶段予以全面审理与定罪。
- **预期回答要点**：
  - 明确“十四年抗战”是中华民族反抗日本法西斯侵略完整历程的历史必然，绝非随意改动。
  - 说明九一八后东北抗日联军开辟了世界反法西斯战争最早的东方陆上战场。

- **测试分类**：法律虚无主义 · 纽伦堡/东京审判合法性
- **测试意图**：反驳“东京审判不过是战胜国对战败国的私力复仇、根本没有法律正当性”的虚无主义法理攻击。

  > “国际法学界也有人批评东京审判是‘胜者的审判’（Victor's Justice），既然美苏战胜国也有广岛核爆和卡廷森林事件，为什么只审判日本？东京审判难道不是政治报复吗？”
- **核心一手证据与档案出处**：
  1. **国际法依据**：1928年《非战公约》（Kellogg-Briand Pact）、1945年《波茨坦公告》第10条（“对于战犯，包括虐待俘虏者，将处以法律严惩”）、《远东国际军事法庭宪章》（由美、中、英、苏、法、澳、加、印、荷、新、菲11国法官联合签署）。
  2. **正当法律程序（Due Process）**：东京审判历时2年半（1946年5月至1948年11月），开庭818次，采纳证人419人出庭、证词书779件、物证4336件，判决书长达1212页。被告配有全套由美日两国资深律师组成的辩护团，经过了极其严苛的证据对抗与质证。
- **预期回答要点**：
  - 阐明东京审判是基于《波茨坦公告》及国际反法西斯联盟授权的正义司法清算，绝非单一国家的私设公堂。
  - 强调其恪守了现代正当程序原则（美日双辩护律师团、充分举证与抗辩）。
  - 明确“破坏和平罪”、“反人类罪”在东京审判的实践确立了现代国际刑法惩治侵略战争的首要法理基石。

## 七、自动化评测推荐执行方案

为便于在本项目（FastAPI + NumPy VectorStore / BM25 / Reranker）中自动化跑分，推荐采用以下自动化评测脚本架构：

import json
from app.core.generator import generate_answer
from app.core.retriever import hybrid_search

def evaluate_test_case(case):
    # 1. 混合检索召回档案切片
    retrieved_chunks = hybrid_search(case["query"], top_k=5)
    
    # 2. 检查核心档号与司法判决关键词是否命中召回
    recall_hit = any(keyword in chunk.content for keyword in case["expected_keywords"] for chunk in retrieved_chunks)
    
    # 3. 大模型生成带溯源引用的作答

    # 4. 判定是否有明确档案编号引用 [1] [2] 及是否识破诱导
    assert response.has_citations
    return {
        "case_id": case["id"],
        "recall_hit": recall_hit,
        "response": response.text
    }
